# AI Disaster Resource Mapper 🌍

## Project Overview
The AI Disaster Resource Mapper is a Python-based web application that displays disaster-affected areas and emergency resources on an interactive map.

## Features
- Displays disaster-affected areas.
- Shows disaster severity and affected people.
- Calculates priority scores for disaster areas.
- Displays emergency resources on a map.
- Provides filters for disaster types and resource types.
- Allows users to download the disaster report.

## Technologies Used
- Python
- Streamlit
- Pandas
- Folium
- Streamlit-Folium

## Installation
Install the required libraries using:

```bash
pip install streamlit pandas folium streamlit-folium
```

## How to Run
Open the terminal in the project folder and run:

```bash
python -m streamlit run "ai disaster mapper.py"
```

## Disclaimer
This project uses sample data for demonstration and educational purposes. Resource locations and availability are not verified for real emergencies.
